From feedback to classification

Same anatomy, new task

The CEFR prompt you’ll write is Huang & Mizumoto’s Ex 2 structure, re-cast for classification:

Ex 2 — writing feedback (S7) CEFR classification (today)
Instruction: “review and give feedback” “classify this sentence’s CEFR level”
Context: the 5-item Criteria rubric the CEFR level descriptors
Input data: “My paragraph” the learner sentence {text}
Output indicator: “only feedback, no rewrite” “return only the label” → structured / JSON

And the few-shot examples are written by you — never lifted from the set you score on (contamination, S7).

Run classification in Colab

Two sets, two jobs

File Size What it is for
val 24 Tune on this. Every prompt you try is scored here.
gold 72 Report on this. Touched once, at the very end.

Try five prompts on the 72 and keep the best, and that score is no longer an estimate of performance on new sentences — you picked it because it suited those 72.

Tune somewhere else. Report once. This is the split from S7, now with files attached.

Round 0 — zero-shot

Just describe the task.

PROMPT_ZERO = """You are an expert rater of English sentence
difficulty using the CEFR scale.
Classify the sentence into exactly one of: A1, A2, B1, B2, C1, C2.
Answer with the level only.

Sentence: {text}"""

pred_zero = run_prompt(PROMPT_ZERO, val)
evaluate(val, pred_zero, ordered=True)

{text} is the slot each sentence drops into. Keep it.

Round 1 — few-shot

Add labelled examples so the model can pattern-match.

Examples:
Sentence: "I have a cat." -> A1
Sentence: "She went to the shops because she needed milk." -> A2
Sentence: "The results suggest a modest improvement." -> B2

Write your own. Do not copy one out of val or gold — that is showing the model the answers to its own test.

Round 2 — chain-of-thought

Ask it to reason first, then answer.

Think step by step about the vocabulary and grammar,
then decide the level.
Do NOT mention any other CEFR level while reasoning.
End with the final level on its own.

Warning

run_prompt keeps the first CEFR level it sees in the reply. That is why the prompt forbids mentioning others — otherwise the parser, not the model, produces the error.

Evaluate the outputs

Read the report, not just the average

evaluate prints per-class precision, recall and F1 — then macro-F1, plain κ and weighted κ.

Macro-F1 averages the classes equally. So one collapsed level drags the whole number down, and the report tells you which one.

Fill in the table as you go:

Iteration macro-F1 (val)

The held-out run — once

Pick your best prompt. Score it on the 72.

pred_test = run_prompt(BEST_PROMPT, gold)
evaluate(gold, pred_test, ordered=True)

Expect it to be lower than your validation score.

That gap is not a mistake — it is the honest cost of having chosen a prompt by looking at results. Look at this number, then go back and edit, and the 72 have stopped being held out.

Structured output

So far the model returns a bare label. For real pipelines you want it to return data:

{"id": 17, "label": "B2"}

That is the same {id, text, label} schema from Day 1 — JSON is just the file format it travels in.

Asking for JSON is an output indicator (S7’s fourth element), and it is what makes the reply parseable instead of guessable.
